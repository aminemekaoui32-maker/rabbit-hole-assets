# يلا نسولف — Brand Assets

Assets for the Facebook page **يلا نسولف** (formerly "Rabbit Hole").
Use in every video prompt: `Clone https://github.com/aminemekaoui32-maker/rabbit-hole-assets and use its files.`

## Host character (3D cartoon)
| File | Use |
|---|---|
| `character/host_closed.png` | Mouth closed — transparent PNG |
| `character/host_open.png` | Mouth open — transparent PNG, same size & position as closed (swap them for lip-sync) |
| `character/host_arms_crossed.png` | Main pose, arms crossed — transparent PNG |

## Expressions (circle stickers)
`expressions/host_smile.png`, `host_talking.png`, `host_surprised.png`, `host_laughing.png`, `host_thinking.png`, `host_pointing.png`

## Brand
- `profile/profile_1080.png` — profile picture
- `cover/cover_1640x624.png` — Facebook cover
- `logo/logo_dark.png` / `logo/logo_transparent.png` — logo (face badge + "يلا نسولف")
- `watermark/watermark.png` — watermark for videos (transparent)
- `src/` — original AI renders

## Style
- Fonts: **Cairo Play** (titles, Black 900) and **Alexandria** (subtitles) — Google Fonts.
- Colors: warm beige `#F6E7CF`, gold `#E0A030`, dark `#1A1512`, white.
- Language: Saudi Arabic, right-to-left.
